Cloud SQL no tiene capa gratuita. A diferencia de BigQuery, cobra por hora aunque nadie la use.

Encender solo cuando toca clase

Un curso de 8 semanas con 2 clases de 3 horas por semana, encendiendo la instancia solo durante la clase:

EscenarioCoste de 2 meses
Siempre encendida≈ 17,20 USD
Solo en clase (48 h de cómputo)≈ 2,50 USD

Apagar

gcloud sql instances patch adk-sessions \
  --project=<TU_PROJECT_ID> \
  --activation-policy=NEVER

Encender

gcloud sql instances patch adk-sessions \
  --project=<TU_PROJECT_ID> \
  --activation-policy=ALWAYS

Buenas prácticas de coste

  • Alerta de presupuesto. Facturación → Presupuestos y alertas: 10 USD al mes para el proyecto. Avisa por correo al 50, 90 y 100 %.
  • Apagar entre clases. El histórico se conserva en el disco; solo se detiene el cómputo.
  • Vigilar el disco. El crecimiento automático está activo: si se llenara, crecería solo y con él el coste. Con un chat no ocurrirá.
  • Borrar al terminar el curso. gcloud sql instances delete adk-sessions. Elimina también el histórico.
  • Dónde ver el gasto real. Facturación → Informes, filtrando por el servicio Cloud SQL. Aparece con varias horas de retraso.

Resumen

Menos de 9 USD al mes encendida. Menos de 1 USD apagada.

La decisión importante no es el tamaño de la máquina, sino acordarse de apagarla.
